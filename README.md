# Merchandise Portal Platform

## Stack
- Backend: Node.js (Express + TypeScript) + MongoDB + Razorpay
- Frontend: React (Vite + TS)

## Setup
1. Backend
   - cd backend
   - copy .env.example to .env and set values
   - npm install
   - npm run dev
   - visit GET http://localhost:4000/health
2. Frontend
   - cd frontend
   - npm install
   - npm run dev
   - open shown localhost port
